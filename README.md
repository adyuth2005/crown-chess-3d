# Crown Chess 3D 👑♟️

A stunning 3D Gothic chess game featuring minimalist cathedral architecture, polished marble vs. obsidian pieces, dynamic camera presets, procedural audio, and multi-fragment shatter physics.

## 🌟 Features
* **Full 32-Piece Match & 64-Square Grid**: Legal move validation, castling, en-passant, and pawn promotions via Chess.js.
* **Dramatic Combat Animation**: Capturing a piece triggers a multi-fragment stone shatter explosion with camera shake and shockwave rings.
* **Crown AI & Local Play**: Play solo against a tactical AI or switch to local 2-player pass mode.
* **Procedural Audio**: Immersive ambient hums, stone slides, and crystalline chimes powered by Tone.js.
* **Mobile Ready**: Optimized for 60 FPS mobile WebGL performance.

## 🛠️ Built With
* **Three.js** - 3D Rendering & Lighting
* **Chess.js** - Chess Logic & Rule Validation
* **Tone.js** - Procedural Sound Effects
* **Tailwind CSS & MD3** - Modern Glassmorphic UI
